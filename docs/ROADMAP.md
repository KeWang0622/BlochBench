# Release status and next steps

## Available in the research preview

- 24 Core task types, 88 frozen data variants, generators, graders and validation records.
- Local agent runners, grading, paired add-on comparisons and a validated community submission format.
- Frozen offline Core results and approved Hard aggregates; no model experiments rerun for this release.
- A task browser, reproducible results tables and downloadable packages.

## Remaining research work

- Independent MRI expert review of task statements, references and grader tolerances.
- Stronger targeted controls and red-team tests, especially for sequence replay and hardware checks.
- Repeated-run reliability and human baselines with a prespecified protocol.
- A maintainer-operated hidden evaluation service, with hash commitments before runs and a declared release policy.
- An archival DOI and additional data mirrors.

These are plans, not completed validation or advertised service guarantees. Hard task definitions, seeds, graders,
solutions, traces and per-task results remain outside the public repository.
